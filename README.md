## Backend API

The MVC project has been refactored into a token-based Web API that supports quiz authoring, taking, and tracking user progress.

### Prerequisites

- .NET 8 SDK
- PostgreSQL 13+
- Google and Microsoft OAuth client IDs (set in `appsettings.Development.json` or environment variables)

### Configuration

1. Copy `appsettings.Development.json` and update:
	- `ConnectionStrings:DefaultConnection`
	- `Jwt:Secret` to a strong random string
	- `OAuth:Google:ClientId`
	- `OAuth:Microsoft:ClientId` and `TenantId` as needed
2. Ensure the PostgreSQL database exists. Apply migrations after generating them (`dotnet ef migrations add InitialCreate`).

### Running Locally

```bash
dotnet restore
dotnet build
dotnet run --project MVC
```

Swagger UI is available at `/swagger` in development.

### Key Endpoints

- `POST /auth/google`, `POST /auth/microsoft`, `POST /auth/refresh`, `POST /auth/logout`, `GET /auth/me`
- `GET /users/me`, `PATCH /users/me`, `DELETE /users/me`
- `POST /quizzes`, `GET /quizzes`, `GET /quizzes/{quizId}`, `PATCH /quizzes/{quizId}`, `DELETE /quizzes/{quizId}`
- `POST /quizzes/{quizId}/questions`, CRUD over `/questions/{id}`
- `GET /quizzes/saved`, `POST /quizzes/{quizId}/save`, `DELETE /quizzes/{quizId}/save`
- `POST /quizzes/{quizId}/attempts`, `PATCH /quizzes/{quizId}/attempts/{id}`, `GET /quizzes/{quizId}/attempts/{id}`
- `GET /results`, `GET /results/{attemptId}`
- `GET /progress`

All endpoints (except OAuth login/refresh) require a bearer JWT generated by the auth flow.
